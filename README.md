# Postly

A simple social media app built with React where users can create, edit, and delete posts.

🔗 Live: https://postly-react.vercel.app/
🔗 GitHub: https://github.com/manojkumar-mern/postly

---

## Features

* Create, edit, delete posts
* Search posts
* Real-time updates
* Responsive UI

---

## Tech Stack

* React (Vite)
* CSS
* Axios
* JSON Server (local)
* MockAPI (deployed)

---

## Setup

```bash
git clone https://github.com/your-username/postly.git
cd postly
npm install
npm run dev
```

---

## API

* Local: http://localhost:3500/posts
* Production: MockAPI
